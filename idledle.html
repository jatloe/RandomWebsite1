Note on the intention of the game (PLEASE READ)

This game is designed for first playthroughs. The intention is for you to figure out what to do under the time pressure of when the game is running. Therefore, although you are welcome to restart and try again, do note that your "official attempt" for the day is the first run you make. Refreshing the page before finishing your first run should be considered a DNF.

If a run was genuinely a first attempt but the website doesn't think so (for example, if you refreshed before you started the game), you are welcome to manually edit the attempt count in the share message. Please do not edit the attempt count otherwise.
